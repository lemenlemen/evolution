## 🎯 痛点与初衷

### 问题 1：AI 的"失忆症"

**问题描述**：

```
┌─────────────────────────────────────────────────────────────┐
│  传统 AI 协作模式                                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  第 1 轮：用户说"项目用 Python 3.11"                         │
│     ↓                                                       │
│  第 10 轮：AI 问"你的 Python 版本是多少？"  ← 忘记了！       │
│     ↓                                                       │
│  第 15 轮：用户重复"是 3.11"                                 │
│     ↓                                                       │
│  第 20 轮：AI 又问"Python 版本？"           ← 又忘了！       │
│                                                             │
│  结果：用户反复回答相同问题，效率低下                         │
└─────────────────────────────────────────────────────────────┘
```

**Evolution 的解决方案**：

```
┌─────────────────────────────────────────────────────────────┐
│  Evolution 协作模式                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  第 1 轮：用户说"项目用 Python 3.11"                         │
│     ↓                                                       │
│  [后台] Knowledge Base Agent 记录到 facts.md                 │
│     ↓                                                       │
│  第 10 轮：AI 自动读取 facts.md，知道是 3.11                 │
│     ↓                                                       │
│  第 15 轮：AI 继续正确使用 3.11                              │
│                                                             │
│  结果：AI 记住关键信息，用户无需重复                          │
└─────────────────────────────────────────────────────────────┘
```

##  核心原理

### 原理 1：索引 + 详情文件架构

```
─────────────────────────────────────────────────────────────┐
│                     知识库架构                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────                                        │
│  │   kb-index.md   │  ← AI 对话开始时自动读取（索引）       │
│  │                 │                                        │
│  │  📊 概览表格     │  ← 告诉 AI 有哪些信息可用             │
│  │  📁 分类摘要     │  ← 引导 AI 按需读取详情               │
│  └────────────────                                         │
│           │                                                 │
│           ↓ 按需读取                                         │
│                                                             │
│  ┌─────────────────┐  ┌─────────────────┐                  │
│  │    facts.md     │  │  pitfalls.md    │  ← 详情文件      │
│  │                 │  │                 │                  │
│  │  • 环境配置     │  │  • 错误模式     │                  │
│  │  • 技术决策     │  │  • 解决方案     │                  │
│  │  • 依赖关系     │  │  • 注意事项     │                  │
│  └─────────────────┘  └─────────────────┘                  │
│                                                             │
│  优势：                                                      │
│  ✅ 索引小（<200 行），快速加载                              │
│  ✅ 详情按需读取，节省 token                                 │
│  ✅ 结构清晰，易于维护                                       │
─────────────────────────────────────────────────────────────┘
```

### 原理 2：增量写入 + 去重机制

```
┌─────────────────────────────────────────────────────────────┐
│                    数据写入策略                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  第一次 /evolution                                          │
│     ↓                                                       │
│  facts.md:                                                  │
│  - [10:00] WSL 网络必须使用镜像模式                          │
│                                                             │
│  第二次 /evolution（2 小时后）                               │
│     ↓                                                       │
│  facts.md:                                                  │
│  - [10:00] WSL 网络必须使用镜像模式  ← 更新时间戳，不新增   │
│  - [12:00] Python 版本必须是 3.11      ← 新增条目            │
│                                                             │
│  规则：                                                      │
│  ✅ 相同信息 → 更新时间戳                                    │
│  ✅ 新信息 → 追加写入                                        │
│  ✅ 状态更新 → 标记为"已完成"                                │
─────────────────────────────────────────────────────────────┘
```

## 🏗️ 系统架构

### 目录结构

```
evolution-manual/
├── agents/                          # Agent 规格说明
│   ├── knowledge-base-agent.md      # 知识提取 Agent
│   ├── growth-agent.md              # 人类成长 Agent
│   ── alignment-agent.md           # 人机对齐 Agent
│
└── knowledge-base/                  # 知识库数据
    ├── kb-index.md                  # 索引文件（AI 对话开始时读取）
    ├── facts.md                     # 关键事实
    ├── pitfalls.md                  # 踩坑记录
    ├── state.md                     # 当前状态
    ├── growth-notes.md              # 学习笔记
    ├── prompt-improvements.md       # Prompt 改进建议
    ├── alignment.md                 # 对齐清单
    └── decisions.md                 # 决策记录
```

### 文件职责

| 文件 | 消费者 | 说明 |
|------|--------|------|
| `kb-index.md` | AI | 索引文件，告诉 AI 有哪些信息可用 |
| `facts.md` | AI | 关键事实（环境配置、技术决策） |
| `pitfalls.md` | AI | 踩坑记录（错误模式、解决方案） |
| `state.md` | AI | 当前状态（任务进度、待确认项） |
| `growth-notes.md` | 人类 | 学习笔记（技术概念解释） |
| `prompt-improvements.md` | 人类 | Prompt 改进建议 |
| `alignment.md` | 人类+AI | 对齐清单（待验收项） |
| `decisions.md` | 人类+AI | 决策记录（待决策项） |

##  三个后台 Agent

### 1. Knowledge Base Agent

```
┌─────────────────────────────────────────────────────────────┐
│              Knowledge Base Agent                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  触发频率：每 5 轮对话                                       │
│                                                             │
│  输入：最近 5 轮对话                                         │
│     ↓                                                       │
│  处理：                                                      │
│  ├── 提取关键事实 → facts.md                                │
│  ├── 提取踩坑记录 → pitfalls.md                             │
│  ├── 更新当前状态 → state.md                                │
│  └── 更新索引 → kb-index.md                                 │
│                                                             │
│  输出：1 行摘要                                              │
│  `KB: +3 facts, +1 pitfall, +2 state updates`               │
│                                                             │
│  去重规则：                                                  │
│  - 相同信息 → 更新时间戳                                     │
│  - 新信息 → 追加写入                                         │
└─────────────────────────────────────────────────────────────┘
```

### 2. Growth Agent

```
┌─────────────────────────────────────────────────────────────┐
│                  Growth Agent                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  触发频率：每 10 轮对话                                      │
│                                                             │
│  输入：最近 10 轮对话                                        │
│     ↓                                                       │
│  处理：                                                      │
│  ├── 识别教学机会 → growth-notes.md                         │
│  └── 分析提问方式 → prompt-improvements.md                  │
│                                                             │
│  输出：1 行摘要                                              │
│  `Growth: +2 notes, +1 prompt tip`                          │
│                                                             │
│  教学价值评估：                                              │
│  🔴 高优先级：用户明确询问、反复出现                          │
│  🟡 中优先级：相关但非核心                                    │
│  🟢 低优先级：边缘概念（跳过）                               │
└─────────────────────────────────────────────────────────────┘
```

### 3. Alignment Agent

```
┌─────────────────────────────────────────────────────────────┐
│                 Alignment Agent                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  触发频率：每 5 轮对话 + 即时触发                            │
│                                                             │
│  输入：最近 5 轮对话                                         │
│     ↓                                                       │
│  处理：                                                      │
│  ├── 识别验收项 → alignment.md                              │
│  ├── 识别决策点 → decisions.md                              │
│  └── 标记高风险操作 → 即时提醒                              │
│                                                             │
│  输出：1 行摘要                                              │
│  `Alignment: +1 audit, +0 decisions`                        │
│                                                             │
│  优先级分类：                                                │
│  🔴 高优先级：安全相关、不可逆操作（立即处理）               │
│  🟡 中优先级：功能验收、技术决策（本轮处理）                 │
│  🟢 低优先级：优化建议（后续处理）                           │
└─────────────────────────────────────────────────────────────┘
```

### 完整流程图

```
用户输入 /evolution
    ↓
┌─────────────────────────────────────────────────────────────┐
│  主 Agent（调度器）                                          │

│  1. 导出全量对话到临时文件                                   │

│  2. 并行启动 3 个 Sub-Agent                                  │
```

##  快速开始

### 1. 安装

将 `evolution-manual/` 和 `.claude/` 目录复制到你的项目根目录：

```bash
# 复制到你的项目
cp -r evolution-manual/ <你的项目>/
cp -r .claude/ <你的项目>/
cp CLAUDE.md <你的项目>/
```

### 2. 使用

在你的项目中打开 Claude Code，然后：

```bash
/evolution          # 执行所有三个 Agent
/kb-sync            # 只同步知识库
/growth-sync        # 只生成学习笔记
/alignment-sync     # 只检查对齐项
```

### 3. 查看结果

Agent 执行后，查看 `evolution-manual/knowledge-base/` 目录：

- `kb-index.md` - 索引文件
- `facts.md` - 关键事实
- `pitfalls.md` - 踩坑记录
- `state.md` - 当前状态
- `growth-notes.md` - 学习笔记
- `alignment.md` - 对齐清单
- `decisions.md` - 决策记录

##  设计理念

> **不要人为制造摩擦。首要目标是把任务完美完成，然后自然而然地把有意义的事情做了。**

Evolution 不是额外的负担，而是任务执行过程中的自然副产品。

### 核心原则

| 原则 | 说明 |
|------|------|
| **任务优先** | 首要目标是完成任务，不是运行系统 |
| **自然发生** | 学习和沉淀在任务执行中自然发生 |
| **人类无感** | 后台运行，不干扰主对话 |
| **渐进成长** | AI 和人类都在协作中成长 |
