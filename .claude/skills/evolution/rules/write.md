# 写入规则（v4.1.6）

## 状态标记

| 状态 | 标记 | 含义 |
|------|------|------|
| draft | `[D]` | AI 提取，未经用户验证 |
| verified | `[V]` | 用户明确确认或工具验证 |
| deprecated | `[X]` | 已废弃或已证实错误 |

## 写入规则

1. **所有新条目默认标记为 `[D]`**
   - Sub agent 直接编辑知识库 markdown 追加条目
   - 格式：`### [D] 条目标题`
   - 示例：`### [D] WSL 网络配置`
   - 写入后更新 `kb-index.md` 索引（<200 行）

2. **以下情况可标记为 `[V]`**：
   - 用户在对话中明确确认（如说"对"、"是的"）
   - 工具调用结果验证（如 `node -v` 输出）
   - 外部文档引用

3. **冲突处理（红线）**：
   - 新条目与已有 `[V]` 条目冲突 → **禁止自动淘汰 `[V]`**
   - 冲突条目并列保留，标注"存在矛盾，待人工裁决"
   - 新条目以 `[D]` 写入，注明与哪条 `[V]` 冲突

4. **未验证条目使用限制（红线）**：
   - `[D]` 条目可读取，但**不作高风险决策的唯一依据**
   - 与 `[V]` 冲突时，以 `[V]` 为准并告警用户
