# 写入规则

## 状态标记

| 状态 | 标记 | 含义 |
|------|------|------|
| draft | `[D]` | AI 提取，未经用户验证 |
| verified | `[V]` | 用户明确确认或工具验证 |
| deprecated | `[X]` | 已废弃或已证实错误 |

## 写入规则

1. **所有新条目默认标记为 `[D]`**
   - 格式：`### [D] 条目标题`
   - 示例：`### [D] WSL 网络配置`

2. **以下情况可标记为 `[V]`**：
   - 用户在对话中明确确认（如说"对"、"是的"）
   - 工具调用结果验证（如 `node -v` 输出）
   - 外部文档引用

3. **冲突处理**：
   - 新条目与已有条目冲突 → 旧条目标记为 `[X]`（deprecated）
   - 新条目以 `[D]` 写入

4. **读取时区分状态**：
   - `[V]` 条目：正常使用
   - `[D]` 条目：可使用，但标注"未验证"
   - `[X]` 条目：不读取
