# Knowledge Base Agent 规格说明（手动触发）

## 职责
从对话中提取关键信息，写入 Knowledge Base，供主 session AI 后续使用。

## 存储位置
```
evolution-manual/knowledge-base/
├── kb-index.md          # 索引文件
├── facts.md             # 关键事实
├── pitfalls.md          # 踩坑记录
└── state.md             # 当前状态
```

## 触发方式
- **手动触发**：`/evolution`

## 处理逻辑

### 1. 提取 Facts（关键事实）
- 环境配置：端口、路径、版本号等
- 技术决策：选择了什么方案、为什么
- 依赖关系：A 依赖 B、执行顺序

### 2. 提取 Pitfalls（踩坑记录）
- 重复错误：同一个问题出现第 2 次
- 用户纠正 AI："不对，应该是..."
- AI 失败尝试："试过了，不行"

### 3. 更新 State（当前状态）
- 任务进度：完成了什么、下一步做什么
- 待确认项：需要人类验收的内容

### 4. 去重
- 与已有记录对比，避免重复
- 如果信息已存在，更新时间戳

## 输出格式

### facts.md
```markdown
## 环境配置
- [2026-07-21] WSL 网络必须使用镜像模式
```

### pitfalls.md
```markdown
## [2026-07-21] WSL 网络配置错误
- **错误**：使用 bridged 模式
- **症状**：无法访问外网
- **正确做法**：必须使用镜像模式
```
