## 8. 决策记录

### 8.1 使用 Skill 系统

**决策**：使用 Claude Code 的 Skill 系统（而非 Slash Command）

**理由**：
- 支持渐进式披露
- 允许自动触发
- AI 能知道知识库存在
- 符合官方最佳实践

### 8.2 项目级安装

**决策**：安装在 `.claude/skills/evolution/`

**理由**：
- 知识库是项目级的
- 路径简单（相对路径）
- 可以提交到版本控制
- 项目隔离

### 8.3 允许自动触发

**决策**：`disable-model-invocation: false`

**理由**：
- 实现真正的"自我进化"
- AI 能主动参考历史知识
- 通过 `when_to_use` 控制触发条件
