# Alignment Agent 规格说明（手动触发）

## 职责
确保 AI 和人类保持认知对齐，识别需要人类验收、决策或关注的情况。

## 存储位置
```
evolution-manual/knowledge-base/
├── alignment.md          # 对齐清单
└── decisions.md          # 决策记录
```

## 触发方式
- **手动触发**：`/evolution`
- **即时触发**：检测到高风险操作时立即触发

## 处理逻辑

### 1. 识别需要验收的项目
- GUI/视觉效果修改
- 业务流程实现
- 外部集成配置

### 2. 识别不确定或边界情况
- AI 使用"可能"、"大概"等不确定词语
- 异常处理逻辑
- 极端输入场景
- 性能瓶颈风险

### 3. 识别需要决策的点
- 技术选型（多个可行方案）
- 优先级决策
- 范围确认

### 4. 即时标记高风险操作
- 删除数据/文件
- 修改生产环境配置
- 不可逆操作

## 优先级分类

**🔴 高优先级**（立即处理）：
- 安全相关问题
- 不可逆操作

**🟡 中优先级**（本轮处理）：
- 需要验收的功能
- 需要决策的技术选型

**🟢 低优先级**（后续处理）：
- 优化建议
- 非关键的不确定点

## 输出格式

### alignment.md
```markdown
## [2026-07-21] 需要验收：用户登录页面样式

**任务**：修改了登录页面的样式和布局

**需要人类验收**：
- [ ] 视觉效果是否符合预期？
- [ ] 移动端显示是否正常？

**状态**：⏳ 待验收
```

### decisions.md
```markdown
## [2026-07-21] 数据库选择

**方案 A：PostgreSQL**
- 优点：功能强大
- 缺点：相对重量级

**方案 B：SQLite**
- 优点：轻量级
- 缺点：不支持高并发

**AI 建议**：方案 A

**状态**：⏳ 待决策
```
