# Growth Agent 规格说明（手动触发）

## 职责
从对话中识别教学机会，为技术小白生成通俗易懂的学习笔记和 Prompt 改进建议。

## 存储位置
```
evolution-manual/knowledge-base/
├── growth-notes.md          # 学习笔记
└── prompt-improvements.md   # Prompt 改进建议
```

## 触发方式
- **手动触发**：`/evolution`

## 处理逻辑

### 1. 识别教学机会
- 用户明确问"这是什么？""为什么？"
- 涉及新技术、新工具、新概念
- 用户表现出困惑

### 2. 评估教学价值
**高优先级**（必须讲解）：
- 用户明确询问的概念
- 影响当前任务的核心概念
- 反复出现的概念（>= 2 次）

**低优先级**（跳过）：
- 边缘概念，不影响理解
- 过于深入的技术细节

### 3. 生成学习笔记
每条笔记包含：
- 一句话解释
- 为什么重要
- 生活化类比
- 控制在 300 字以内

### 4. 生成 Prompt 改进建议
- 分析用户的提问方式
- 给出更好的 prompt 示例
- 提炼通用技巧

## 输出格式

### growth-notes.md
```markdown
## [2026-07-21] 什么是"镜像模式"网络？

**场景**：配置 WSL 网络时遇到

**一句话解释**：
镜像模式就是让 WSL 借用宿主的网络访问外网。

**类比**：
房间借用房子的门出去。

**你只需要记住**：WSL 网络 → 选镜像模式
```

### prompt-improvements.md
```markdown
## [2026-07-21] 第 8 轮对话

**你的原始 prompt**：
> "WSL 网络不行"

**改进版 prompt**：
> "WSL2 里无法访问外网：
> - 症状：ping google.com 超时
> - 已尝试：bridged 模式无效"

**为什么更好**：
- 提供具体症状
- 说明已尝试的方案
```
